# Room Studio

누구나 자기 집 도면과 가구로 공간을 살펴볼 수 있는 웹 도구의 **개발 중인 기반 프로젝트**입니다. 완성된 공개 서비스가 아닙니다. Codex 앱에서 이 폴더를 열고 기능 보완과 배포를 이어갈 수 있습니다.

## 처음 시작한다면

1. GitHub에서 이 저장소를 복제하고 Node.js 22.13 이상을 준비합니다.
2. 프로젝트 폴더에서 `npm ci`, 이어서 `npm run dev`를 실행하고 터미널에 표시된 주소를 엽니다.
3. Codex 앱에서 같은 폴더를 열어 프로젝트 실행·개선·배포를 요청합니다.

**[Codex 앱으로 시작하기: 복제부터 가구 제작·배포 준비까지](docs/CODEX-시작하기.md)** 에 단계별 설명과 복사해 쓸 수 있는 요청 예시가 있습니다.

```bash
git clone https://github.com/taeiin/room-studio.git
cd room-studio
npm ci
npm run dev
```

개발 중 변경 사항의 빌드는 `npm run build`로 확인합니다. 저장소를 복제하거나 GitHub에 푸시하는 것만으로 웹사이트가 공개되지는 않습니다.

## 지금 사용할 수 있는 기능

- 빈 프로젝트에서 도면 이미지(PNG/JPEG/WebP)를 올리고 상하 반전합니다.
- 도면의 방 후보를 실험적으로 감지하고, 선택한 후보를 추가하거나 직접 방을 그려 이동·크기 조정합니다.
- 한 방의 가로 치수로 축척을 맞추고, 직사각형 방을 단순한 3D 공간으로 봅니다.
- Codex 앱 등에서 별도로 제작한 GLB를 이름·치수와 함께 등록하고 선택한 방에 배치·이동·회전합니다.
- 현재 브라우저에 저장하고, 도면·방·GLB와 배치를 백업 파일로 내려받아 다른 PC에서 수동으로 불러옵니다.

다은마을 도면은 선택적으로 불러오는 예시입니다. 기존 다은마을 전용 코드와 모델 파일은 참고용으로 저장소에 포함되어 있지만 새 프로젝트에 기본 배치되지는 않습니다.

## 아직 필요한 작업

- **도면 자동 인식:** 현재 후보 감지는 오탐과 누락이 많고, 문·창문이나 실측 치수는 판독하지 못합니다. 사용자가 직접 확인해야 합니다.
- **3D 정확도:** 현재 방은 직사각형으로 단순화됩니다. 시공이나 실측 판단에 사용할 수 없습니다.
- **Codex 연결:** 웹에서 Codex가 자동 실행되는 방식이 아닙니다. 각자가 Codex 앱에서 모델을 만든 뒤 GLB를 직접 등록합니다.
- **계정과 동기화:** 저장은 브라우저별이며 백업 파일을 통한 수동 이전만 됩니다. 사용자별 서버 저장은 구현되지 않았습니다.
- **배포:** 독립 호스팅과 GitHub 자동 배포는 설정되지 않았습니다. 기존 서버 코드는 Sites 전용 인증 및 저장소에 의존하므로 독립 환경의 인증과 저장소를 구현·검증해야 합니다. 상세한 주의사항은 [Codex 시작 안내](docs/CODEX-시작하기.md)를 참고하세요.

## 백업 옮기기

원래 PC에서 **백업 내려받기**를 누르고 `room-studio-backup.json`을 다른 PC로 전달한 뒤 **백업 불러오기**를 선택합니다. 파일에 도면과 가구 모델이 포함되며, 불러올 때 현재 프로젝트의 교체 여부를 확인합니다. 백업은 최대 100MB, GLB 한 개는 최대 40MB입니다. 양쪽 PC의 변경 사항이 자동으로 합쳐지지는 않습니다.

이 저장소는 공개되어 있습니다. API 키, 비밀번호와 공개하면 안 되는 자료는 커밋하지 마세요. 변경 이력은 [CHANGELOG.md](CHANGELOG.md)를 확인하세요.
