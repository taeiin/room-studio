# Room Studio

사용자가 집 도면과 가구를 바탕으로 공간을 살펴보는 웹 서비스를 개발하는 프로젝트입니다.

## 현재 상태

**초기 개발 단계입니다.** 새 화면은 도면과 가구가 없는 상태로 시작합니다. 이미지를 선택하면 브라우저에서 임시로 미리 볼 수 있습니다. 미리보기는 저장되지 않으며 새로고침하면 사라집니다.

아래 기능은 새 화면에 아직 연결되지 않았습니다.

- 도면의 벽·방·치수 자동 인식 및 3D 공간 생성
- Codex 앱에서 제작한 가구 모델 등록과 방에 배치
- 사용자 로그인과 프로젝트 저장·불러오기
- 공개 서비스 호스팅 및 GitHub 자동 배포

기존 다은마을 전용 코드와 도면·가구 모델 파일이 참고용으로 저장소에 포함되어 있지만 초기 화면에서는 사용하지 않습니다. 기존 서비스의 데이터베이스, 브라우저 임시 저장 데이터, 사용자가 업로드한 파일은 Git 저장소에 포함되지 않습니다.

## 내 PC에서 실행

준비물: Git과 Node.js 22.13 이상.

```bash
git clone https://github.com/taeiin/room-studio.git
cd room-studio
npm ci
npm run dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 엽니다. 종료하려면 터미널에서 `Ctrl+C`를 누릅니다. 빌드 확인은 `npm run build`로 실행합니다.

## Git으로 작업 이어가기

다른 PC에서 시작할 때는 위의 `git clone`을 한 번 실행합니다. 이미 복제한 PC에서는 작업 전에 아래 명령으로 최신 코드를 가져옵니다.

```bash
git switch main
git pull origin main
```

변경 사항을 GitHub에 올릴 때는 변경 내용을 확인하고 커밋합니다.

```bash
git status
git add .
git commit -m "변경 내용 설명"
git push origin main
```

이 저장소는 **공개 저장소**입니다. 비밀번호, API 키, 개인 파일 및 다른 사람에게 공개하면 안 되는 자료는 커밋하지 마세요. `.env` 파일과 빌드 결과물, 의존성 폴더는 Git에서 제외됩니다.

## 배포에 대해

GitHub는 코드를 보관하며, `git push`만으로 현재 이 프로젝트의 웹 서비스가 자동으로 만들어지지는 않습니다. 별도 호스팅과 빌드·배포 설정을 연결해야 합니다.

현재 저장소의 서버 코드는 기존 OpenAI Sites 환경의 인증 헤더와 Cloudflare D1/R2 저장소에 의존합니다. 독립 서비스로 배포하기 전에는 신뢰할 수 있는 로그인·서버 인증을 구현하고, 프로젝트 DB와 파일 저장소를 새로 연결해야 합니다. 외부에서 전달된 인증 헤더를 그대로 신뢰하는 방식으로 공개 운영해서는 안 됩니다. 기존 `.openai/hosting.json`의 프로젝트 식별자는 이전 Sites 프로젝트용이므로 다른 배포 환경에서 그대로 사용하지 마세요.

자동 배포의 목표 흐름은 **GitHub에 코드 푸시 → 연결된 호스팅에서 빌드 → 검증 후 배포**입니다. 호스팅 업체와 계정, 저장소 연동이 아직 설정되지 않았으므로 현재 자동 배포는 동작하지 않습니다.

## 계획

1. 도면 업로드와 치수 기준 설정, 방·벽 인식 및 사용자의 수정 기능.
2. 2D/3D 공간 표시, 방 선택과 가구 이동·회전.
3. 상품 링크·사진을 바탕으로 Codex 앱에서 가구 모델 제작 후 GLB 파일을 등록하는 수동 작업 흐름.
4. 사용자별 프로젝트·모델 저장과 보안 검증, 독립 서비스 배포.
