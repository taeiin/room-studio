# Room Studio

도면과 가구가 비어 있는 새 프로젝트에서 시작하는 인테리어 웹 서비스입니다.

현재 초기 화면과 도면 이미지 임시 미리보기만 제공됩니다. 도면 자동 인식·3D 공간 생성, 사용자별 저장, Codex에서 제작한 가구 등록은 새 서비스에 아직 연결되지 않았습니다. 기존 다은마을 전용 코드는 이 초기 화면에 연결되어 있지 않습니다.

## 개발

Node.js 22.13 이상에서 `npm ci`, `npm run dev`로 실행합니다. 기존 앱은 Sites 전용 인증 헤더와 Cloudflare D1/R2에 의존하므로 이를 독립 환경에서 인증 검증 없이 공개 운영하지 마세요. 기존 서버 데이터와 업로드 파일은 이 저장소에 들어 있지 않습니다. GitHub 업로드만으로 웹이 배포되지는 않습니다.
