# Room Studio

사용자가 자기 집 도면과 가구를 바탕으로 공간을 살펴보는 웹 서비스를 개발하는 프로젝트입니다.

## 현재 기능

- 빈 프로젝트에서 도면 이미지(PNG/JPEG/WebP)를 선택하고, 상하 반전할 수 있습니다.
- 도면에서 방의 양쪽 모서리를 지정해 직사각형 방을 만들고 이름을 바꿀 수 있습니다.
- 한 방의 실제 가로 치수를 입력하면 공통 축척을 적용하여 다른 방 크기를 추정합니다.
- 지정한 방들을 3D로 보고, 회전·확대 및 방 선택을 할 수 있습니다.
- 명시적으로 선택할 때만 다은마을 도면과 수동 추정 방 영역을 예시로 불러옵니다. 거실 발코니 확장은 개략적으로 표시하며 침실 2 발코니는 방에 합치지 않습니다.
- 프로젝트를 현재 브라우저에 저장하고 다시 불러옵니다. 서버 동기화나 다른 기기 공유는 지원하지 않습니다.

도면의 벽·방·문·창문 자동 인식은 아직 구현되지 않았습니다. 모든 방은 직사각형이며 3D 벽에는 문·창문이 표현되지 않으므로 정확한 실측이나 시공 기준으로 사용할 수 없습니다. 예시 영역과 축척으로 계산한 치수는 모두 개략치입니다.

Codex 앱으로 제작한 가구의 등록·배치, 사용자별 서버 저장 및 서비스 배포도 아직 새 화면에 연결되지 않았습니다. 기존 다은마을 전용 소스와 가구 파일은 참고용으로 포함되어 있습니다. 기존 서비스의 데이터베이스와 업로드 파일은 Git에 들어 있지 않습니다.

## 내 PC에서 실행

Git과 Node.js 22.13 이상이 필요합니다.

```bash
git clone https://github.com/taeiin/room-studio.git
cd room-studio
npm ci
npm run dev
```

터미널에 표시된 주소를 엽니다. 빌드 확인은 `npm run build`를 실행합니다.

## Git 작업

기존 PC에서 작업 전 `git pull origin main`으로 최신 코드를 가져옵니다. 작업 후 `git status`로 내용을 확인하고 `git add .`, `git commit -m "변경 내용"`, `git push origin main`으로 공유합니다. 공개 저장소이므로 인증 정보와 공개하면 안 되는 파일은 올리지 마세요.

## 배포

GitHub는 코드 저장소이며 현재 자동 배포는 연결되어 있지 않습니다. 서버 코드는 기존 Sites 인증 헤더와 Cloudflare D1/R2에 의존하므로, 독립적인 인증·데이터베이스·파일 저장소를 구현하고 배포 환경에 맞게 설정해야 합니다. 외부에서 전달된 인증 헤더를 검증 없이 신뢰해 공개 운영해서는 안 됩니다. 기존 `.openai/hosting.json`의 프로젝트 식별자는 이전 Sites 프로젝트용입니다.

변경 이력은 [CHANGELOG.md](CHANGELOG.md)를 확인하세요.
