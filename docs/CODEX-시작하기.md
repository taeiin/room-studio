# Codex 앱으로 시작하기

Room Studio는 바로 공개 서비스로 운영할 수 있는 완성품이 아니라, Codex와 함께 이어서 만들 수 있는 초기 프로젝트입니다.

## 1. 저장소를 내 PC에 받기

Git과 Node.js 22.13 이상을 설치한 뒤 터미널에서 실행합니다.

```bash
git clone https://github.com/taeiin/room-studio.git
cd room-studio
npm ci
npm run dev
```

터미널에 표시된 주소로 접속합니다. 이미 복제한 경우 해당 폴더에서 `git pull origin main`으로 최신 코드를 가져올 수 있습니다. 본인의 GitHub 저장소에 수정 내용을 올리려면 원본 저장소를 fork하거나 쓰기 권한이 있어야 합니다. 저장소 복제만으로 웹사이트가 공개 배포되지는 않습니다.

## 2. Codex 앱에서 프로젝트 열기

Codex 앱에서 복제한 `room-studio` 폴더를 작업 폴더로 선택합니다. 이 저장소에는 프로젝트 구조와 주의사항을 설명하는 `AGENTS.md`가 포함되어 있습니다. Codex에게 아래처럼 요청할 수 있습니다.

> 이 저장소의 README와 AGENTS.md를 읽고 로컬에서 실행해 줘. 기존 기능을 확인한 후 내가 도면을 올리고 방을 지정해 3D로 볼 수 있는지 시험해 줘. 작동하지 않는 부분은 고치고 결과와 남은 제약을 알려줘.

## 3. 우리 집 도면과 가구로 시작하기

1. 웹에서 도면 이미지를 올립니다. 자동 방 감지는 실험 기능이므로 도면에 표시된 후보를 검토하고, 필요한 방을 직접 추가·수정합니다.
2. 알고 있는 실제 가로 치수를 입력해 축척을 설정하고 3D 공간을 확인합니다. 결과는 간략한 직사각형 모델이며 문·창문과 정확한 실측은 아직 자동 처리하지 않습니다.
3. Codex 앱에 상품 링크 또는 사진, 가로·깊이·높이, 색상과 소재를 전달합니다. 예시 요청:

   > 이 상품의 사진과 치수를 참고해 Room Studio에서 사용할 GLB 가구 모델을 제작해 줘. 가로 1200mm, 깊이 400mm, 높이 940mm이고 화이트야. 모델의 근사치와 확인하지 못한 부분도 알려줘.

4. 완성된 GLB를 웹의 **가구 보관함 → 추가**에서 직접 등록하고 선택한 방에 놓습니다. 상품 사이트 접근 제한이나 제공 사진 부족에 따라 모델 정확도는 달라질 수 있습니다.
5. **이 기기에 저장**하거나 **백업 내려받기**로 도면·가구가 포함된 파일을 보관합니다. 다른 PC에서는 백업 파일을 전달하고 **백업 불러오기**를 사용합니다.

Codex 앱 이용 가능 여부와 사용 한도는 각자의 계정과 환경에 따릅니다. 이 웹은 Codex를 자동 호출하지 않습니다.

## 4. 내 서비스로 배포를 계속하려면

호스팅을 선택하기 전 아래 요청을 Codex에 전달해 현재 환경과 비용을 확인하세요.

> 이 저장소를 내 계정으로 독립 배포하고 싶어. 무료로 시작할 수 있는 호스팅을 우선 검토하고, 기존 Sites 전용 인증과 저장소 의존성을 확인해 줘. 내 데이터를 다른 사용자와 분리할 인증과 저장 방법을 구현하고, 로컬 및 배포 환경에서 검증해 줘. 비용이 드는 설정은 먼저 설명해 줘. 비밀키는 채팅이나 Git에 적지 않도록 안내해 줘.

현재 저장소에는 자동 배포 설정이 없으며, 사용자별 로그인·서버 저장도 완성되지 않았습니다. `app/api`의 기존 Sites 전용 인증 헤더를 독립 환경에서 검증 없이 신뢰하도록 배포하면 안 됩니다. 계정 생성, 호스팅 연결, 도메인과 결제 관련 설정은 사용자 환경에 따라 별도로 필요합니다.
